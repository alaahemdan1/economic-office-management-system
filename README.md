# 🏢 نظام إدارة المكتب الاقتصادي

## المميزات الرئيسية

✅ **5 خدمات كاملة:**
- 📊 الدراسات الاقتصادية
- 🏢 تأسيس الشركات
- 📜 التراخيص والموافقات
- 💼 الفرص الاستثمارية
- 🏞️ الأراضي والمناطق

✅ **نظام الدفعات المتقدم:**
- إجمالي الاتعاب المتفق عليها
- الدفعة الأولى والثانية
- حساب المبلغ المتبقي تلقائياً
- حساب نسبة السداد

✅ **إدارة كاملة CRUD:**
- إضافة سجلات جديدة
- تعديل السجلات الموجودة
- حذف السجلات
- عرض بجداول منظمة

✅ **تصدير PDF:**
- تحميل جداول البيانات كـ PDF
- عملية تصدير سريعة وسهلة

✅ **التصميم العصري:**
- واجهة جميلة وسهلة الاستخدام
- دعم العربية بالكامل
- دعم الأجهزة المختلفة (Responsive Design)
- عملات مصرية (ج.م)

- Node.js 20.19+

## التثبيت المحلي

```bash
# 1. استنساخ أو تحميل المشروع
cd economic-office-management-system

# 2. تثبيت المكتبات
npm install

# 3. تشغيل الخادم (Development)
npm run dev

# 4. افتح المتصفح على:
# http://localhost:5175
```

---

## البناء للإنتاج

```bash
npm run build
```

سينشئ مجلد `dist` جاهز للنشر على أي استضافة ويب.

---

## البيانات والتخزين

✅ **التخزين المحلي (localStorage)**
- لا تحتاج قاعدة بيانات منفصلة
- البيانات آمنة وخصوصية عالية
- تعمل بدون اتصال إنترنت (بعد التحميل الأول)
- حد أقصى ~10 MB يكفي لآلاف السجلات

## خيارات النشر

اختر أحد الخيارات التالية:

### 🌟 **Netlify** (الأسهل والأفضل)
```bash
npm install -g netlify-cli
npm run build
netlify deploy --prod --dir=dist
```

### 🚀 **Vercel**
```bash
npm install -g vercel
vercel
```

### 📄 **GitHub Pages**
```bash
# تأكد من أن المشروع عام
npm run build
# ارفع على GitHub وفعّل Pages من الإعدادات
```

### 🏠 **استضافة مشتركة (Shared Hosting)**
1. ابن المشروع: `npm run build`
2. ارفع مجلد `dist` كاملاً إلى `public_html`

### 🖥️ **VPS خاص**
```bash
npm install -g pm2
npm run build
pm2 start "npm run preview" --name "office-system"
pm2 startup
pm2 save
```

انظر [DEPLOYMENT.md](./DEPLOYMENT.md) للتفاصيل الكاملة.

## الاستخدام

### إضافة سجل جديد
1. اختر الخدمة (الدراسات، الشركات، إلخ)
2. ملأ البيانات المطلوبة
3. أدخل تفاصيل الدفعات
4. اضغط "إضافة/تعديل"

### تعديل سجل
1. اضغط "تعديل" على السجل
2. غير البيانات التي تريدها
3. اضغط "تعديل" مجدداً

### حذف سجل
اضغط "حذف" الزر الأحمر

### تحميل PDF
اضغط "تحميل PDF" لتحميل الجدول كملف PDF

## حل المشاكل الشائعة

### ❌ الخطأ: "Port already in use"
```bash
# استخدم منفذ مختلف
npm run dev -- --port 3000
```

### ❌ البيانات لا تُحفظ
تأكد من أن localStorage متفعّل في المتصفح:
- افتح Developer Tools (F12)
- اذهب إلى Application → Local Storage

### ❌ PDF لا يُحمّل
تأكد من أن الجدول يحتوي على بيانات قبل التحميل
